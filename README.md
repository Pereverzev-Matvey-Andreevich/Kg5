# KG5.1

Откройте KG5.1/KG5.1.slnx в Visual Studio 2026 с установленными компонентами C++ и Windows SDK. Выберите **x64** и нажмите **F5**. MSBuild копирует ресурсные файлы в папку сборки.

- **T** переключает сцены Sponza и ландшафта. Положение камеры сохраняется для каждой сцены.
- **WASD**, **Q/E** перемещают камеру. Удерживайте правую кнопку мыши для поворота и **Shift** для ускорения.
- **G** включает и выключает отсечение по фрустуму, **L** окрашивает уровни детализации и обводит границы тайлов, **F** включает каркас.

Ландшафт размером 512×512 включает извилистый каньон с уступами и четыре вершины. Карта высот разбита на 64 16-битных тайла PGM по 33×33 отсчёта. В одном тайле 32×32 ячейки. Соседние тайлы используют одинаковые значения высоты на общей границе. Чтобы заново сгенерировать карты высот, выполните `py tools/generate_heightmaps.py` из корня репозитория.

Квадродерево выбирает четыре уровня детализации по расстоянию до границ узла. Сетки LOD 0–3 имеют 32×32, 16×16, 8×8 и 4×4 ячеек. Каждый следующий уровень покрывает вдвое большую область по каждой оси, а шаг между вершинами вырастает в четыре раза. Перед выбором LOD фрустум отсекает целые ветви дерева. Вертикальные полосы по краям тайлов закрывают щели между уровнями. Заголовок окна показывает число отрисованных треугольников, включая полосы, тайлы по уровням и число отсечённых узлов.

Источники текстур и условия атрибуции указаны в [Sponza/CREDITS.md](KG5.1/Assets/Sponza/CREDITS.md).
